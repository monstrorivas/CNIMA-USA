Admin payment check

Private tool for CNIMA USA organizers. Nothing here writes to Google Sheets or sends email.

The value of ADMIN_CHECK_SECRET in Netlify. It is sent in a request header, never in the URL, and is not stored.

1. Health check

Read-only. Checks Stripe, PayPal, Google Sheets and Resend settings. Creates one Stripe Checkout Session and expires it immediately.

2. $1 card test (Stripe)

Charges exactly $1.00 through the same embedded Stripe Checkout as registration. Creates no registration and no spreadsheet row, and sends no email. Afterwards, refund it in the Stripe dashboard.

3. $1 PayPal test

Charges exactly $1.00 through PayPal, using the same PayPal buttons as registration. Creates no registration and no spreadsheet row, and sends no email. Afterwards, refund it in PayPal.
